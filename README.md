# thestreet-web

Giao diện **trang thi tăng cấp** và **trang quản trị** của THE STREET, phục vụ qua GitHub Pages và nhúng vào WordPress.

- Đoạn nhúng WordPress: xem [WORDPRESS.md](WORDPRESS.md)
- Hướng dẫn cho Claude và người phát triển: xem [CLAUDE.md](CLAUDE.md)

## Bật GitHub Pages (làm 1 lần)
Settings → Pages → *Build and deployment*: Source = **Deploy from a branch**, Branch = **main**, thư mục **/ (root)** → Save.
Sau 1–2 phút, file có tại `https://thestreet-admin.github.io/thestreet-web/admin/admin.js`.
